#                        source /usr/local/gromacs/bin/GMXRC
#
#   AmberTools           conda install -c conda-forge ambertools
#                        provides: antechamber, parmchk2, tleap,
#                                  amb2gro_top_gro.py
#
# Optional, for binding free energy in step 17 of docs/WORKFLOW.md:
#
#   gmx_MMPBSA           pip install gmx_MMPBSA
#
# Optional, if you prefer it to amb2gro_top_gro.py for Amber -> GROMACS:
#
#   acpype               pip install acpype
